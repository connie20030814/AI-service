# AI-service
# 🧠 社會科學文本分析服務 (LLM-Powered Text Analyzer)

本專案旨在為 **社會科學領域的研究者** 打造一套易用、強大且可本地運行的文本分析工具。  
透過整合 **Ollama 大型語言模型 (LLM)** 與 NLP 工具，本網站可對新聞、報告、社會議題文本（例如 DEI 議題）進行深度語意與結構分析。

---

## 🌟 核心主題
- AI 文本分類  
- 社會語意分析  
- 關鍵詞與框架探索  
- 共現網絡建構  

---

## ⚙️ 技術架構

| 組件 | 技術 / 模型 | 功能 |
|------|--------------|--------|
| **網站前端 / 後端** | Streamlit | 建立互動式資料分析網站 |
| **AI 核心引擎** | Ollama API | 呼叫本地 LLM 做語意推理與情感分析 |
| **LLM 模型** | deepseek-v3.1:671b-cloud | 高精度中文語義理解與零樣本分類 |
| **NLP / 統計工具** | Pandas, Jieba, NetworkX, scikit-learn | 文字前處理、TF-IDF、關鍵詞分析、概念共現圖 |

---

- **Python 3.11 / 3.12（建議）**
- 已安裝並啟動 **Ollama**
- 已下載指定模型
