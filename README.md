# AI-service
# 🧠 社會科學文本分析服務 (LLM-Powered Text Analyzer)

本專案旨在為 **社會科學領域的研究者** 打造一套易用、強大且可本地運行的文本分析工具。
透過整合 **Ollama 大型語言模型 (LLM)** 與 NLP 工具，本網站可對新聞、報告、社會議題文本（例如 DEI 議題）進行深度語意與結構分析。

---

## 🌟 核心主題
- AI 文本分類
- 社會語意分析
- 關鍵詞與框架探索
- 共現網絡建構

---

## ⚙️ 技術架構

| 組件 | 技術 / 模型 | 功能 |
|------|--------------|--------|
| **網站前端 / 後端** | Streamlit | 建立互動式資料分析網站 |
| **AI 核心引擎** | Ollama API | 呼叫本地 LLM 做語意推理與情感分析 |
| **LLM 模型** | deepseek-v3.1:671b-cloud | 高精度中文語義理解與零樣本分類 |
| **NLP / 統計工具** | Pandas, Jieba, NetworkX, scikit-learn | 文字前處理、TF-IDF、關鍵詞分析、概念共現圖 |

---

## 🖥️ 系統需求
- Python 3.11 / 3.12（建議）
- 已安裝並啟動 Ollama
- 已下載指定模型：
  ```bash
  ollama pull deepseek-v3.1:671b-cloud
🚀 主要功能
1️⃣ AI 情感傾向分析（Ollama）
使用 DeepSeek LLM 進行：

正面 / 負面 / 中性分析

可作為輿情監測或議題定位

2️⃣ 關鍵詞頻率分析（Jieba）
統計詞彙出現頻率，快速掌握文本集的主題輪廓。

3️⃣ TF-IDF 關鍵詞提取
識別最具代表性的詞彙。

4️⃣ 概念共現網絡分析（NetworkX）
以概念共現圖呈現語意結構與概念連結強度。

🧭 使用方式（Usage）
本網站提供研究者一套完整的文本資料流程，從資料上傳、AI 推論到視覺化分析。

1. 準備資料
上傳格式必須是 CSV，且包含：

欄位名稱	說明
Content	要分析的文本內容（必填）

2. 啟動網站後
在左側側邊欄依序操作：

上傳 CSV 檔案

選擇要啟用的分析功能（可多選）

按下 「執行 Ollama 情感分析」 進行推論
⏳ 首次使用深度模型時推理時間較長，屬正常現象

3. 查看輸出結果
網站會顯示：

情感分析結果表格

詞頻統計長條圖

TF-IDF 代表性詞彙

概念共現網絡圖（NetworkX）

每個模組都有可展開的 expander，方便逐一查看研究結果。
